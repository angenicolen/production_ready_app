# Changelog

Toutes les modifications importantes du projet TaskFlow sont documentées dans ce fichier.

## [1.0.0] - 2026

### Ajouté
- Application complète de gestion de tâches
- Navigation entre cinq écrans
- Création, suppression et modification de l'état des tâches
- Statistiques sur les tâches
- Support du français et de l'anglais
- Validation des formulaires
- Support de l'accessibilité avec des labels sémantiques
- Tests unitaires, tests de widgets et tests d'intégration
- Analyse statique du code avec `flutter analyze`

## [0.2.0] - 2026

### Ajouté
- Mise en place des tests unitaires
- Mise en place des tests de widgets
- Ajout des tests d'intégration
- Internationalisation français/anglais
- Écran des paramètres
- Écran des statistiques

## [0.1.0] - 2026

### Ajouté
- Création de l'application TaskFlow
- Modèle `Task`
- Service `TaskService`
- Écran d'accueil
- Écran de gestion des tâches
- Écran d'ajout d'une tâches
- Navigation principale de l'application
